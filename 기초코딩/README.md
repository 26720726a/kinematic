# RISE LAB 기초 코딩 대비

성균관대학교 RISE LAB 코딩 테스트의 **기초 코딩 1문제**를 대비하기 위해
난이도 1~10단계로 구성한 Python 연습문제입니다.

> 주의: 아래 문제는 공식 기출문제가 아니라 연습용 예상문제입니다.

## 파일 구성

| 파일 | 내용 | 난이도 |
|---|---|---|
| 01_array_sum.py | 배열의 합 | ★ |
| 02_above_average.py | 평균보다 큰 값의 개수 | ★ |
| 03_max_index.py | 최댓값과 위치 | ★★ |
| 04_nearest_point.py | 원점에서 가장 가까운 점 | ★★ |
| 05_matrix_vector.py | 행렬 × 벡터 | ★★★ |
| 06_moving_average.py | 이동 평균 | ★★★ |
| 07_robot_command.py | 로봇 이동 명령 처리 | ★★★ |
| 08_total_distance.py | 로봇 전체 이동 거리 | ★★★★ |
| 09_outlier_filter.py | 센서 이상치 제거 | ★★★★ |
| 10_bfs_shortest_path.py | 격자 최단 경로 BFS | ★★★★★ |

## 실행 방법

각 파일은 구름 코딩테스트와 동일하게 표준 입력(`input()`)을 사용합니다.

```bash
python 01_array_sum.py
```

실행 후 예제 입력을 직접 입력하면 됩니다.

## 추천 학습 순서

- 1~5단계: 반드시 코드 없이 작성할 수 있을 것
- 6~8단계: 문제 조건이 바뀌어도 수정할 수 있을 것
- 9단계: 센서 데이터 처리 연습
- 10단계: 알고리즘 문제가 나올 경우를 위한 보험
